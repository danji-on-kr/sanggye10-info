# 단지온 · 상계주공10단지 정보 페이지

입주민이 만든 **비공식** 정보 페이지입니다. 관리주체나 입주자대표회의의 공식 서비스가 아닙니다.

공개된 자료를 한곳에 모아 보기 쉽게 정리하는 것이 전부입니다.

## 무엇을 보여주나

- **단지 소식** — 입주자대표회의 공고·회의록 등 공개 게시물 요약
- **관리 투명성 현황** — 확인이 끝난 사항과 아직 확인 중인 사항
- **관리비 항목별 추이** — 2025년 대비 2026년 (원/㎡)

## 자료 출처

- K-apt 공동주택관리정보시스템 (k-apt.go.kr)
- 서울시 공동주택 통합정보마당 (openapt.seoul.go.kr)
- 노원구청 공개 문서

각 항목에 출처를 함께 표기했습니다. 원문은 위 사이트에서 직접 확인하실 수 있습니다.

## 지키는 선

- 특정인의 위법행위를 주장하거나 단정하지 않습니다.
- 확인이 끝난 사항은 "확인됨"으로 정정해 표시합니다.
- 주민 개인정보는 수집하지도, 저장하지도 않습니다. 이 저장소에는 공개자료만 있습니다.

## 파일 구조

```
index.html    페이지 본문 (단독 실행, 빌드 불필요)
data.json     관리비 지표·타임라인·쟁점 데이터
```

`index.html`은 `data.json`을 읽어 화면 값을 채웁니다. 읽기에 실패하면 HTML에 적힌 값이 그대로 표시됩니다(폴백).

`data.json`은 단지코드별 구조라, 다른 단지 자료를 넣으면 그대로 재사용할 수 있습니다.

## 갱신

공개 게시물을 주기적으로(화·금) 확인해 새 내용이 있을 때 갱신합니다.

마지막 갱신일은 페이지 상단 "기준일"과 `data.json`의 `updatedAt`에 표시됩니다.

### 새 글 확인

```
python check_updates.py
```

서울시 통합정보마당 게시판 목록을 받아 직전 확인 시점과 비교해 **새 글만** 알려줍니다.
로그인도 브라우저도 필요 없습니다.

| 종료코드 | 뜻 |
|---|---|
| 0 | 새 글 없음 |
| 1 | 새 글 있음 (목록 출력) |
| 2 | 확인 실패 (네트워크 오류 또는 사이트 구조 변경) |

새 글이 나오면 내용을 확인한 뒤 `data.json`과 `index.html`을 갱신합니다.
직전 확인 상태는 `_snapshot.json`에 저장되며 저장소에는 올리지 않습니다.
